보물타워 - 타워 종류 / 능력치 정리
(코드 기준: src/config/towers.ts, 2026-09-10 기준)

=====================================================
1. 기본 타워 (basic)
=====================================================
설명      : 단일 대상, 균형 잡힌 화력
설치 비용 : 50 골드
사거리    : 150
공격력    : 22
공격속도  : 550ms (한 발당)
투사체 속도: 600
특수효과  : 없음 (단일 대상 직접 타격)

=====================================================
2. 스플래시 타워 (splash)
=====================================================
설명      : 범위 피해, 적이 몰려있을 때 강력
설치 비용 : 90 골드
사거리    : 120
공격력    : 16 (명중 대상 기준, 주변 적은 60%만 적용)
공격속도  : 1100ms
투사체 속도: 420
특수효과  : 스플래시 반경 65 이내 적 전체에게 피해

=====================================================
3. 슬로우 타워 (slow)
=====================================================
설명      : 피해는 약하지만 적을 둔화시킴
설치 비용 : 70 골드
사거리    : 140
공격력    : 6
공격속도  : 900ms
투사체 속도: 480
특수효과  : 피격 대상 이동속도 45%로 감소 (1.5초 지속)

=====================================================
레벨 / 업그레이드 시스템
=====================================================
최대 레벨    : Lv2 (MAX_TOWER_LEVEL = 2)
레벨 배율    : Lv2 = 기본 스탯의 1.6배 (데미지, 사거리)
업그레이드 비용 : 설치비용 × 0.8 × 현재레벨
                 예) 기본타워 Lv1→Lv2 = 50 × 0.8 × 1 = 40 골드
판매 가치    : 지금까지 투자한 총 비용 × 0.6

=====================================================
[논의 중 / 미구현] 향후 확장 아이디어
=====================================================
- 합성(Fusion) 시스템
  : Lv2(최대 레벨) 타워 2개를 골드 소모하여 상위 타워 1개로 합성
  : 1차는 "동종 합성" (같은 타입끼리)부터 시작 예정
    예) 기본타워 Lv2 + 기본타워 Lv2 → "기본타워 Ω" (자리 1칸 절약, 대폭 강화)
  : 추후 "이종 합성"(예: 기본+슬로우 → 저격형, 스플래시+슬로우 → 빙결폭발) 확장 가능
  : 좁은 맵(14x8)에서 배치 공간 확보라는 전략적 의미 부여

- 진행도 저장
  : 현재는 세션(브라우저 새로고침) 종료 시 초기화됨
  : 1차는 localStorage로 세션 간 저장 (서버 불필요)
  : 유료 코인 충전(PG 결제) 도입 시에는 BE + DB 필수
    (클라이언트 값은 조작 가능하므로 실제 돈이 얽히면 서버 검증 필요)
