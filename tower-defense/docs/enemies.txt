보물타워 - 적(몬스터) 종류 / 능력치 정리
(코드 기준: src/config/enemies.ts, 2026-09-10 기준)

=====================================================
1. 그런트 (grunt) - 기본 잡몹
=====================================================
체력      : 60
이동속도  : 62 px/sec (기준)
처치 보상 : 10 골드
색상      : 빨강 (#dd4444)
반경      : 14
특징      : 가장 흔한 표준형, 모든 웨이브에 자주 등장

=====================================================
2. 패스트 (fast) - 고속형
=====================================================
체력      : 32 (그런트보다 약함)
이동속도  : 115 px/sec (그런트의 약 1.85배)
처치 보상 : 8 골드
색상      : 노랑 (#dddd44)
반경      : 11 (작음)
특징      : 체력 낮지만 빨라서 슬로우 타워로 견제하기 좋음

=====================================================
3. 탱크 (tank) - 고체력형
=====================================================
체력      : 230 (그런트의 약 3.8배)
이동속도  : 34 px/sec (느림)
처치 보상 : 26 골드
색상      : 보라 (#8844dd)
반경      : 19 (큼)
특징      : 단일 타겟 화력이 필요, 스플래시 타워 효율 낮음(적이 몰려있지 않으면)

=====================================================
4. 보스 (boss) - 최종 웨이브 전용
=====================================================
체력      : 2000 (탱크의 약 8.7배)
이동속도  : 40 px/sec
처치 보상 : 250 골드
색상      : 검정 (#222222)
반경      : 30 (가장 큼)
특징      : 10웨이브(최종)에 1마리만 등장, 그런트 10마리를 앞세우고 등장

=====================================================
웨이브별 난이도 스케일링
=====================================================
- 웨이브가 진행될수록 체력 배율 증가: hpMultiplier = 1 + (웨이브 인덱스 × 0.12)
  예) 5웨이브 체력 배율 = 1 + 4×0.12 = 1.48배
- 총 10웨이브 구성, 웨이브별 등장 구성:

  1웨이브 : 그런트 x8
  2웨이브 : 그런트 x10, 패스트 x4
  3웨이브 : 그런트 x10, 탱크 x3
  4웨이브 : 패스트 x10, 그런트 x6
  5웨이브 : 탱크 x6, 패스트 x8
  6웨이브 : 그런트 x14, 패스트 x8, 탱크 x4
  7웨이브 : 패스트 x14, 탱크 x6
  8웨이브 : 탱크 x10, 패스트 x10, 그런트 x10
  9웨이브 : 그런트 x16, 패스트 x16, 탱크 x8
  10웨이브(보스) : 그런트 x10, 보스 x1

=====================================================
[논의 중 / 미구현] 향후 확장 아이디어
=====================================================
- 적 이미지: 현재 색상 원(circle) placeholder 상태, 타워처럼 SVG 스프라이트 교체 예정
- 신규 적 타입 후보: 회복형(주변 적 힐), 분열형(죽을 때 소형 2마리로 분열), 은신형(슬로우 타워만 감지 가능) 등
