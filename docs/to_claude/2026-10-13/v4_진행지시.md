## 1. 이번 작업의 단일 완료선

C2-4는 다음 장면 하나만 완성한다.

```text
CH02_MAZE_CLEARED
→ 안전 물길 너머 위기 지점 도착
→ 누비 색 빠짐 연출
→ 누비가 주인공 이름을 잊음
→ 주인공이 이름을 다시 알려 줌
→ 누비가 이름을 기억함
→ CH02_NUBI_CRISIS_SEEN
```

전투, 아이템, 성장, 보스 입장 기능은 추가하지 않는다.

## 3. 발동과 서버 사건

- `CH02_MAZE_CLEARED`와 `lake_safe_route_opened`를 모두 가진 플레이어만 발동할 수 있다.
- C2-3의 내부 안전 물길 너머 `anchor_maze_exit` 부근에 위기 지점을 둔다.
- 서버가 플레이어 위치와 지점 반경을 검증한다.
- 안정적인 사건 ID는 기존 정본대로 `lake_nubi_crisis_seen`을 사용한다.
- 장면 완료 요청이 성공하면 `lake_nubi_crisis_seen`과 `CH02_NUBI_CRISIS_SEEN`을 같은 트랜잭션으로 기록한다.
- 직접 사건 요청, 원거리 요청, 선행 체크포인트 누락 요청을 거부한다.
- 직렬·동시 중복 완료는 사건 1건과 체크포인트 1회로 멱등 처리한다.

## 4. 정본 장면

`docs/scene/2장.md`의 `잊어버린 이름` 구간을 문구와 순서대로 옮긴다.

필수 내용:

- 염색 샘에 가까워질수록 누비의 색이 더 빠르게 빠지는 서술
- 누비: `저기…….`
- `{playerName}`: `왜 그래?`
- 누비가 이름을 기억하지 못하는 대사
- 주인공이 자신의 이름을 다시 알려 주는 대사
- 누비가 `{playerName}`을 되뇌고 기억을 되찾는 대사
- 다음에는 정말 돌아오지 않을까 두려워하는 누비
- 물빛 염색실을 되찾겠다는 주인공의 약속

`{playerName}`은 서버가 저장한 이름으로 치환한다. 사용자가 다시 이름을 입력하게 하지 않는다.

장면 중간에 새로고침하면 사건·체크포인트를 완료하지 않고 장면 처음부터 다시 재생한다. 장면 완료 뒤에는 반복하지 않는다.

## 5. 연출

- 대화 시작 직전에 `nubi-color-drain` 6프레임을 8~10fps로 한 번 재생한다.
- 오버레이는 누비 중심과 같은 피벗에 표시하고 캐릭터 자체를 대체하지 않는다.
- 장면 동안 월드 채도를 부드럽게 낮추되 HUD·대화창·이름 텍스트는 탈색하지 않는다.
- 누비가 이름을 기억한 뒤 채도는 일부만 안정화한다. 완전한 색 회복 효과는 사용하지 않는다.
- 붉은 화면, 체력 감소, 실패 문구, 시간 제한, 화면 전체 섬광, 강한 흔들림을 사용하지 않는다.
- 장면 종료 뒤 누비의 기능·능력치·파티 상태는 바뀌지 않는다.
- 연출을 빠르게 넘겨도 마지막 대사와 서버 완료 요청이 누락되지 않게 한다.

## 6. 목표와 재접속

장면 전 목표:

```text
누비의 상태를 살피며 염색 샘으로 가자.
```

장면 완료 뒤 목표:

```text
누비를 지키기 위해 염색 샘으로 가자.
```

- `CH02_MAZE_CLEARED`: 열린 내부 문과 위기 지점을 복원한다.
- 장면 재생 중 미완료 상태: 재접속하면 위기 지점에서 처음부터 다시 본다.
- `CH02_NUBI_CRISIS_SEEN`: 위기 지점과 장면은 사라지고 다음 목표만 표시한다.
- C2-5 보스 시작 지점은 이번에 만들거나 활성화하지 않는다.

## 7. 시험

### 단위·통합

1. 위기 지점이 지도 안이며 벽·깊은 물과 겹치지 않음
2. 선행 체크포인트·사건 누락 시 거부
3. 원거리·위조 지점 요청 거부
4. 정본 대사 순서와 `{playerName}` 치환
5. 장면 중간 종료 시 사건·체크포인트 미변경
6. 완료 시 사건과 `CH02_NUBI_CRISIS_SEEN` 한 트랜잭션
7. 직렬·동시 중복 멱등 처리
8. 완료 전·중·후 재접속 상태
9. HP·아이템·통화·누비 능력치 변화 없음
10. `nubi-color-drain` 파일·6×192 프레임·1회 재생 계약
11. `nubi-color-restore` 미사용

### 최소 E2E

C2-4 전용 E2E 파일 하나에 다음을 묶는다.

1. 1280×720: 위기 지점 → 색 빠짐 → 이름 망각 대사 → 완료
2. 장면 중간 새로고침 → 처음부터 재생 → 체크포인트는 완료 뒤에만 변경
3. 완료 뒤 새로고침 → 장면 미반복과 다음 목표
4. 640×360: 효과가 누비 얼굴·대화창·이름·HUD를 가리지 않음

## 9. 검증 속도 정책

- 구현 중 변경 파일의 직접 단위 시험만 실행한다.
- C2-4 전용 E2E 파일을 **1회** 실행한다.
- `story`, `map`, `battle`, `visual`, `layout-qa` 그룹 전체를 실행하지 않는다.
- 단계별 E2E 목표는 2분 안팎이며 5분을 넘으면 중단하고 보고한다.
- 60초 동안 상태 변화가 없으면 반복 대기하지 말고 멈춘 테스트와 로그를 확인한다.
- `for`, `while`, `sleep` 종료 감시 루프를 사용하지 않는다.
- 실패 수정 뒤 실패한 파일만 1회 재실행한다.
- 이미 통과한 시험을 같은 단계에서 다시 실행하지 않는다.
- 캡처만을 위한 별도 E2E 재실행을 하지 않는다.

5분 초과 시 다음을 보고한다.

```text
멈춘 테스트
로그 경로
프로세스 종료 여부
```

검증 비용 표:

