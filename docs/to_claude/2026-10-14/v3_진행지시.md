## 3. 장착 조건

인벤토리의 `water_dye_yarn` 상세 화면에서 다음을 모두 만족할 때만 `누비에게 장착` 버튼을 활성화한다.

1. 체크포인트 `CH02_BOSS_DEFEATED`
2. `lake_boss_aftermath_seen` 완료
3. `lake_boss_defeated`와 `lake_dye_thread_granted` 존재
4. 플레이어가 `water_dye_yarn` 1개 소유
5. 서버가 지정한 이야기 누비 인스턴스를 소유
6. 해당 누비가 판매·삭제 불가 이야기 동료
7. 누비의 `story_1`에 첫 매듭 장착됨
8. 누비의 `story_2`가 비어 있음
9. 누비 성장 단계가 정확히 1

다른 터비, 다른 플레이어의 누비, 위조 인스턴스 ID, 일반 장비 API, 선행 사건 없는 계정은 거부한다.

## 4. 원자적 완료 트랜잭션

장착 승인 시 한 트랜잭션으로 처리한다.

1. 이야기 누비의 `story_2` 슬롯에 `water_dye_yarn` 장착
2. 누비 성장 단계 `1 → 2`
3. `lake_dye_thread_equipped` 1회 기록
4. `underfloor_unlocked` 1회 기록
5. 3장 `underfloor` 입장 권한 개방
6. 체크포인트 `CH02_COMPLETE`

`water_dye_yarn` 보유 레코드는 삭제하지 않는다. 장착된 이야기 유물로 소유 상태를 유지한다.

직렬·동시 5건, 네트워크 재시도, 새로고침, 완료 요청 재전송에서도 슬롯·성장·사건·입장 권한은 한 번만 변경되어야 한다. 하나라도 실패하면 전체 롤백한다.

## 5. 색 회복 에셋과 연출

원본:

```text
design/save-a-turby/chapter02-lake/delivery-v5/fx/story/nubi-color-restore.png
```

런타임:

```text
save-a-turby/src/assets/fx/story/nubi-color-restore.png
```

키 `nubi-color-restore`, 1152×192, 6×192×192, 8~10fps, 1회 재생.

- C2-4의 `nubi-color-drain`과 같은 누비 중심·피벗을 사용한다.
- 회복은 1→6 프레임 순서로 재생한다. drain 시트를 역재생해 대체하지 않는다.
- 누비 그림을 대체하지 않고 투명 오버레이로 겹친다.
- 채도는 C2-4의 0.65 안정 상태에서 포근한 원래 수준으로 천천히 회복한다.
- 화면 전체 흰색 섬광·네온·후광·왕관·종장 외형을 사용하지 않는다.
- 누비의 정체 기억이나 태초의 실타래 진실을 공개하지 않는다.

## 6. 정본 장면

`docs/scene/2장.md`의 `돌아온 색` 구간을 문구·순서대로 옮긴다.

필수 내용:

1. 물빛 염색실이 물들이에게 반응하지 않고 누비에게 다가가는 서술
2. 주인공이 실을 누비 몸 한쪽에 감고 푸른 줄무늬와 색이 돌아오는 서술
3. 누비: `따뜻해. 물속인데도 네 손을 잡고 있는 것 같아.`
4. `{playerName}`: `내 이름은?`
5. 누비: `{playerName}. 이번에는 바로 기억났어.`
6. 염색 샘 바닥의 울림과 푸른 실이 마루바닥 밑으로 이어지는 서술
7. 물들이: `저 울림은 집의 가장 오래된 틈에서 올라오고 있어.`

장면 중간 새로고침 시 트랜잭션은 반복하지 않고 장면 처음부터 재생한다. 장면 완료 뒤에는 반복하지 않는다.

장착 트랜잭션과 장면 완료를 구분하기 위해 다음 일회성 사건을 사용한다.

```text
lake_chapter_complete_seen
```

- 선행: `lake_dye_thread_equipped`, `underfloor_unlocked`, `CH02_COMPLETE`
- 장면 끝까지 확인하면 1회 기록
- 체크포인트·보상·성장을 다시 변경하지 않음

## 7. 완료 후 UI와 3장 개방

- 인벤토리 누비 패널의 `물빛 염색실 슬롯`을 `장착됨`으로 표시한다.
- 물빛 염색실의 잠금과 판매·삭제 금지는 유지한다.
- 누비 성장 단계 2를 상태 화면에 표시한다.
- 지역 선택 화면에 `3장 — 마루바닥 밑`을 개방한다.
- 다음 목표:

```text
마루바닥 밑에서 들려오는 울림을 따라가자.
```

- 3장 입장은 가능하게 하되 3장 이야기·맵·장면을 이번에 만들지 않는다. 아직 콘텐츠가 없다면 자연스러운 준비 문구를 기존 잠금/준비 상태 UI로 표시하고 개발자 문구는 노출하지 않는다.

## 11. 검증 속도 정책

- 구현 중 변경 파일의 직접 단위 시험만 실행한다.
- C2-6 전용 E2E 파일을 1회 실행한다.
- `story`, `map`, `battle`, `visual`, `layout-qa` 그룹 전체를 실행하지 않는다.
- E2E 목표 2분 안팎, 5분 초과 시 중단·보고한다.
- 60초간 상태 변화가 없으면 로그와 멈춘 테스트를 확인한다.
- `for`, `while`, `sleep` 종료 감시 루프를 금지한다.
- 실패 수정 뒤 실패한 파일만 1회 재실행한다.
- 이미 통과한 C2-5A/B 시험을 다시 실행하지 않는다.
- 캡처만을 위한 별도 E2E 실행을 하지 않는다.
