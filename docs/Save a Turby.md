# 터비 훔치기 (Steal a Turby) 기획안

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명(국문) | 터비 훔치기 |
| 프로젝트명(영문) | Steal a Turby (스틸 터비) |
| 장르 | 방치형 수집 + 실시간 침입/미니게임 |
| 참고작 | 로블록스 "Steal a Brainrot(브레인롯 훔치기)" |
| 원안 변경 이력 | 소재명 "마리오 훔치기" → 저작권 문제로 "터비 훔치기"로 변경 |
| 시리즈 순번 | 신규 게임 프로젝트 내 6번째 게임 |

## 2. 캐릭터 컨셉 — 터비(Turby)

- "별의 커비"의 커비를 모티브로 한 오리지널 캐릭터명
- 외형: 털실(Yarn) 모양의 상상 속 캐릭터
- 커비 시리즈의 파생 캐릭터 구조(스워드 커비, 탱장어, 디디디대왕 등)를 참고하여, 터비도 등급/속성별 파생 캐릭터를 두는 방향으로 계획
    - **[미확정]** 파생 캐릭터 목록, 속성별 역할, 등급과의 연관 규칙

## 3. 핵심 게임 루프

```
100원으로 시작
   → 레드카펫(중앙 공통 마켓)에서 터비 구매
   → 기지에서 방치 수익 획득
   → 수익으로 더 좋은 터비 재구매
   → 다른 플레이어 기지 습격
   → 발각 시 미니게임 승부
   → 승자가 터비 획득
   → (반복)
```

## 4. 시스템 상세

### 4.1 시작 및 자금
- 플레이어는 100원을 소지하고 시작
- **레드카펫 = 모든 플레이어가 공유하는 중앙 공통 마켓**. 개인 소유 공간이 아니며, 여러 등급의 터비가 이 공용 마켓에 지속적으로 지나다님
- **진행 방식(원게임 기준)**: 캐릭터(터비)가 스타트 지점에서 등장해 레드카펫을 걸어감 → 종료 지점 도달 시 사라짐(구매 기회 소멸). 그 사이 구간에서 원하는 캐릭터를 자신의 재화로 구매 가능
- 등장하는 캐릭터는 **랜덤** (단, 별도 이벤트 발생 시는 예외)
- 자금 충분 시 구매 가능 / 부족 시 "돈이 부족합니다" 메시지 후 해당 터비는 그대로 지나감
- **[미확정]** 동시 접속한 다른 플레이어와 레드카펫(마켓)을 실시간 공유하는지(선점 경쟁 발생), 아니면 플레이어별로 동일한 마켓이 독립 인스턴스로 보이는지

### 4.2 기지 생활 및 수익
- 구매한 터비는 플레이어 기지에 배치됨
- 시간 경과에 따라 자동으로 수익 발생 (방치형)
- 터비 레벨이 높을수록 수익 증가
- 수익을 재원으로 레드카펫에서 추가 구매 → 루프 반복

### 4.3 터비 등급 체계
- 다수의 등급 존재 (구체 등급명/개수는 **[미확정]**)
- 등급이 높을수록:
    - 레드카펫 등장 확률 ↓ (희귀)
    - 판매(환금) 가치 ↑
    - 훔치기 미니게임 난이도 ↑
- 등급이 낮을수록: 등장 확률 ↑, 판매 가치 ↓

### 4.4 기지 구조 (최대 3층)
| 층 | 진입 방식 | 비고 |
|---|---|---|
| 1층 | 기본 진입 | 별도 조건 없음 |
| 2층 | 계단 이용 | — |
| 3층 | 숨겨진 통로/사다리 | 발견 난이도 있음 |

- 각 층에 터비 보관 가능
- 방어 시스템 설정에 따라 특정 층 통로가 잠길 수 있음

### 4.5 침입 및 방어 시스템
- 다른 플레이어의 기지에 침입해 좋은 등급의 터비를 훔칠 수 있음
- 침입 시 레이더가 침입자를 감지
- 방어 장치(예: 방망이류 아이템)로 침입자를 일시 행동불능화 가능
    - 예시 수치: 약 3초간 이동 불가
- 행동불능 시간 동안 터비가 안전지대로 대피하면 훔치기 실패 처리
- **[미확정]** 레이더 외 추가 방어 장치 종류, 행동불능 시간 밸런스 수치

### 4.6 미니게임 (훔치기 승부)
- 침입자가 발각되면 미니게임으로 승부, 승자가 터비 획득
- 미니게임은 랜덤으로 등장
- 최초 플레이 시 튜토리얼 제공
- 터비 등급이 높을수록 미니게임 난이도 상승
    - 난이도 조절 요소: 시간 제한, 퍼즐 복잡도, 조작 난이도 (혼합 적용)
- **[미확정]** 미니게임 종류(수), 각 미니게임 구체 룰

## 5. 미확정 항목 (다음 결정 필요)
1. 터비 파생 캐릭터 목록 및 등급 연동 규칙
2. 등급 체계 상세 (등급명, 개수, 등장 확률/판매가 수치)
3. 미니게임 종류 및 개별 룰 설계
4. 방어 시스템 종류 확장 여부 (레이더+행동불능 아이템 외)
5. 화폐/수익/레벨업 밸런스 수치 전반
6. 멀티플레이 구조(동시 접속 인원, 서버/동기화 방식 등)
