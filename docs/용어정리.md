# 용어정리

모노레포 전체(허브 + 게임들)에서 쓰는 용어를 정리합니다. 코드/문서/대화에서 이 이름들을 그대로 사용합니다.

## 공통 (hub)

| 용어 | 뜻 |
|---|---|
| 허브 (hub) | 게임을 고르고 들어가는 진입 앱. React로 구현, 각 게임(Phaser)을 캔버스로 얹어서 띄움 |
| 대시보드 | 허브 진입 시 첫 화면. 프로필 + 게임 선택 |
| 라운지 | 게임을 고른 뒤 실제 플레이 전에 들어오는 화면 (공지/설정/라운드 선택/영웅 선택/채팅 등). 코드상 컴포넌트명은 아직 `Lobby` |
| 라운드 | 게임 안의 스테이지 단위. 라운드마다 맵/목표/설정이 다를 수 있음 |
| 코인 | 라운드 클리어 시 얻는 영구 재화. 로컬(localStorage)에 저장, 라운지에서 영웅 강화/아이템 구매에 쓸 예정 |
| 플레이 로그 | 로컬(IndexedDB)에 남는 게임 활동 기록. 난이도/버그 분석용, 서버 전송 없음 |

## 디펜스타워 (tower-defense)

일반 모드. 유저가 타워를 지어 몰려오는 적을 막는 정통 타워디펜스.

| 용어 | 뜻 |
|---|---|
| 타워 | 기본/스플래시/슬로우 3종. 유저가 골드로 설치 |
| 웨이브 | 적이 몰려오는 한 회차. 총 10웨이브 |
| 몬스터(적) | 그런트/패스트/탱크/보스 4종 |
| 골드/라이프 | 유저 자원 / 남은 목숨 |

## 오펜스 타워 (offense-tower)

리버스 모드. 공격자=AI(타워를 자동으로 지음), 수비자=유저(유닛을 소환해서 뚫음). "오타"라고도 부름.

| 용어 | 뜻 |
|---|---|
| 유닛 | 유저가 무료로 소환하는 병력. 물량형/탱커형/스피드형 3종, 각자 타워 상성(강함/약함)이 있음 |
| 영웅 | 상성 삼각형 밖의 4번째 존재. 라운드당 1회 소환, 모든 타워에 고정 내성, 타워를 직접 공격해서 부술 수 있음. 목적지 도달(돌파) 시 재소환 가능, 죽으면 그 판은 재소환 불가 |
| 영웅존 | 맵 위에 표시되는 해금 체크포인트. 일반 유닛이 여기(시드타워 병목)를 실제로 통과해야 영웅 소환 잠금이 풀림 |
| 시드타워 | AI가 게임 시작과 동시에 강제로 짓는 첫 타워 (병목 구간에 위치) |
| 돌파 | 유닛(또는 영웅)이 죽지 않고 맵 끝까지 도달하는 것. 유저 쪽 성공 지표 |
| 처치 | AI 타워가 유닛을 죽이는 것. AI 골드 획득 조건 |
| 클리어 목표 | 라운드마다 정해진 "영웅 제외 유닛 돌파 횟수". 달성 시 그 라운드 클리어 + 코인 보상 |
| AI 골드 | AI가 유닛 처치로 얻어 자동으로 타워를 짓는 데 쓰는 자원 |
| 라운드(Stage) | `offense-tower/src/config/stages/` 아래 라운드별 파일(`round1.ts` 등)로 관리. 맵 경로, 시드타워/영웅존 위치, 클리어 목표를 담음 |

## 전략 알까기 (strategy-marbles)

3번째 게임. 여러 명이 알을 튕겨 상대를 판 밖으로 쳐내는 대전 게임. (기획 초기 단계, 상세는 `docs/전략_알까기_기획안.md` 참고)

| 용어 | 뜻 |
|---|---|
| 방(room) | 참가자 수/알 개수를 정하고 만드는 대전 단위. 2인 이상 가변 |
| 알 무게(저항도) | 알마다 다른 값. 본인 알의 무게만 확인 가능(상대는 비공개) — 정보 비대칭 전략 요소 |
| 턴제 + 동시 처리 | 전원이 각자 행동을 고르고, 전원 완료 시점에 물리 이동/충돌을 동시에 처리 |
| 아웃 | 상대 알을 판 밖으로 쳐내는 것 (100점) |
