# 터비 구하기 — 2장 완성 계획

기준일: 2026-10-13  
목표: `2장 — 어항 속 호수`를 1장 완료 직후부터 물빛 염색실 장착과 3장 개방까지 플레이 가능한 상태로 만든다.

## 1. 완료 정의

1. `CH01_COMPLETE` 플레이어가 단일 호수 맵에 입장한다.
2. 호수 입구·정착지·물결북 장면이 정본 대사대로 재생된다.
3. 물풀 미로에서 물살·젖은 실밥이·물들이 구조 목표가 동작한다.
4. 누비 이름 망각 위기 장면이 체크포인트와 재접속 규칙을 지킨다.
5. 물먹은 박음이 보스전의 검은 실 제거·색 복구·약점 노출이 서버 판정으로 동작한다.
6. 승리 후 물빛 염색실이 한 번만 지급되고 누비 `story_2`에 장착된다.
7. 누비 성장 단계가 2가 되고 `CH02_COMPLETE`와 3장 개방이 한 트랜잭션으로 처리된다.
8. 패배·이탈·새로고침·중복 요청으로 진행과 보상을 위조할 수 없다.
9. 최종 비반복 호수 배경과 상태 오브젝트가 연결된다.
10. 1280×720·640×360에서 길·목표·대화·전투 HUD가 식별된다.
11. BE·프런트 단위 시험, 관련 E2E, 전체 병렬 E2E와 프로덕션 빌드가 통과한다.

## 3. 맵·에셋 기준

`design/save-a-turby/chapter02-lake/asset-contract-v1.md`를 따른다.

- 3200×2400 단일 연속 맵
- 대형 비반복 배경
- 입구 → 정착지 → 물풀 미로 → 염색 샘 순서
- 진행 상태가 바뀌는 요소는 투명 오브젝트로 분리
- 기능 좌표와 최종 미술 좌표를 구분

## 4. 검증 정책

- 모든 보체일전 지시서는 `docs/dev/save-a-turby/handoff_and_verification_policy.md`를 적용하고 검증 속도 정책을 본문에 직접 포함한다.
- 작은 변경: 관련 단위 시험과 E2E 그룹만 실행
- 맵·이동 계약 변경: `story`와 `map`
- 전투 변경: `story`와 `battle`
- UI·에셋 변경: `visual`과 `layout-qa`
- 완료 후보: 전체 병렬 E2E
- main 병합·배포 전: 기존 순차 기준선 또는 승인된 동등 검증

단, 그룹 이름은 자동 실행 기준이 아니다. 각 단계 지시서에서 명시적으로 허용한 파일 또는 그룹만 실행한다. 단계별 E2E는 5분을 넘기지 않으며 반복 셸 대기를 사용하지 않는다.
