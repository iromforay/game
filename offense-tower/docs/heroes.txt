오펜스 타워 - 영웅 시스템 정리
(코드 기준: src/config/heroes.ts, src/scenes/GameScene.ts, 2026-09-10 기준)

=====================================================
1. 영웅 개요
=====================================================
영웅은 물량형/탱커형/스피드형 삼각형 밖의 4번째 축 — 특정 타워 상성 없이
모든 타워에 고정 데미지 감소(내성)를 받는 대신, 소환 자체가 희소하다.

=====================================================
2. 뱅가드 (vanguard) - 현재 유일한 영웅
=====================================================
체력      : 260
이동속도  : 55 px/sec
처치 보상 : 40 골드 (AI가 뱅가드를 처치했을 때)
타워 내성 : 전 타워 공통 40% 데미지 감소 (resistance: 0.6)
타워 공격력 : 20
공격 사거리 : 90
공격 주기   : 800ms (초당 25딜)
설명      : 모든 타워에 내성을 가진 만능형 영웅. 목적지 도달 시 재소환 가능.

=====================================================
3. 영웅존 (소환 해금 조건)
=====================================================
- 게임 시작 시 영웅은 잠겨 있음. 소환 버튼도 비활성 상태로 시작.
- 해금 조건: 일반 유닛(물량/탱커/스피드) 중 1기 이상이 시드 타워가 지키는
  병목 구간(맵 좌표 col9/row3, PATH_GRID index 2)을 실제로 통과해야 함.
- 맵에 항상 금색 "영웅존" 타일로 표시되고, 해금되면 초록색으로 전환됨.
- 폐기된 대안:
  a) AI 타워 개수 기준 → "결국 유닛을 희생해야 하는 이상한 시스템" 이라 기각
  b) 경과 시간 기준 → "유닛 생산 안 하고 대기만 해도 풀리는 루트"라 기각
  → 게임플레이 진행과 직접 연결된 "영웅존 통과" 방식으로 확정
- 난이도 평가(유저 플레이테스트): 너무 어렵지도 쉽지도 않고 적당함. 추가 조정 불필요.

=====================================================
4. 소환/재소환 규칙 (비대칭)
=====================================================
- 목적지까지 무사히 도달(돌파) → 재소환 가능 (성공에 대한 보상)
- 타워에 맞아 사망 → 재소환 불가, 그 판에서는 끝
- 즉 "쿨타임"이 아니라 "성과 기반 재사용" 구조

=====================================================
5. 타워 공격 (상호 전투)
=====================================================
- 확정 규칙: "영웅은 타워를 공격한다. 영웅도 타워의 공격을 받는다."
- 영웅 생존 중 사거리 내 가장 가까운 타워를 주기적으로 자동 공격
- 타워 파괴 시 AI에게 골드 보상 없음 (유닛 처치와 다르게 의도적으로 무보상)
- 파괴된 타워 자리는 AI가 이후 자동으로 재건축 가능 (별도 로직 불필요, 기존
  건설 로직이 자연스럽게 처리함)
- 밸런스 이력: 최초 45dmg/500ms(초당 90딜)로 시작 → 플레이테스트에서 "영웅
  등장 시 타워가 너무 쉽게 무너진다"는 피드백 → 20dmg/800ms(초당 25딜)로 하향
  (타워 파괴 소요시간: 기본 5.6초 / 스플래시 8초 / 슬로우 6.4초)

=====================================================
[논의 중 / 폐기 / 미구현] 관련 기록
=====================================================
- 스킬 시스템: "이지스"(2초 무적, 쿨타임 8초)로 시작했으나, 영웅이 타워를
  직접 부술 수 있게 되면서 무적 스킬의 존재 의미가 약해진다는 지적이 나와
  일단 전부 제거함 (완전 폐기 아님, 보류). 나중에 "타워 공격과 시너지 나는
  방향"(예: 짧은 시간 공격력/공격속도 버프)으로 재설계 가능성 있음.
- 영웅 사진 커스터마이징: 유저가 사진을 업로드해서 영웅 외형으로 사용하는
  기능. IndexedDB에 로컬 저장하는 방식으로 설계됐으나 미구현.
- 영웅 복수 로스터 / "영웅 관리" 화면: 지금은 뱅가드 1명 고정. 추후 여러
  영웅을 만들고 라운지에서 선택하는 구조로 확장 예정.

=====================================================
[아이디어만, 미구현] 라운지 아이템 시스템
=====================================================
- hub에서 게임 선택 후 진입하는 화면(현재 코드상 이름은 Lobby)을 "라운지"로
  부르기로 함.
- 라운지에서 추후 "아이템"을 구매/사용할 수 있게 할 구상:
  · 영웅 부활
  · 영웅 공격력 증가
  · 유닛 속도업
  · 유닛 방어력업
- 재화(무엇으로 구매하는지), 라운지 내 소모품인지 영구 강화인지는 아직
  논의되지 않음. 순수 아이디어 메모 단계이며 구현 착수 전임.
